Use rules:
- Use `apple-hig-designer` for the visual language: typography scale, system colors, spacing, radius, materials, and component patterns.
- Use `web-design-guidelines` for semantic HTML, accessibility (WCAG 2.2 AA), responsive layout, and motion preferences.
- Do not ship Apple trademarks, the Apple logo, SF Pro font files, or SF Symbols assets. Use the system font stack and inline SVG icons you draw yourself.

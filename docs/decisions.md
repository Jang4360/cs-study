# 확정 결정 로그

대화에서 사용자가 확정한 것만 적는다. 제안·미정은 맨 아래 '미정'에 둔다. 새 결정은 날짜와 함께 위에서부터 추가한다.

## 학습 철학·목표 (2026-11-20)
- 목표: CS를 바탕으로 AI의 제안을 이해·검증·안전하게 적용하는 판단력. 모호한 문제에서 계층을 좁히고, 가설을 세우고, 무엇을 확인할지 정하고, 로그·설정·데이터로 판단한다.
- 용어 암기·정답 맞히기가 최종 목표가 아니다. 장애 대응만 공부하려는 것도 아니다.
- 핵심 기준: "답을 숨겨서 어렵게 만들지 말고, 증거를 연결하는 과정에서 생각하게 만든다."
- 첫 사용자는 본인. 만족하면 공유한다. 대규모 공개를 전제로 설계하지 않는다.
- 콘텐츠 기둥(분야 축과 별개): ① 요청이 끝까지 흐르는 과정 ② DB와 동시성 ③ 분산 시스템 실패 처리 ④ 관측과 안전한 변경. AI 학습도 목표지만 커리큘럼은 미정.

## 서비스 구조
- 두 모드 (2026-11-20 확정, 2026-11-20 v0.2에서 경계 재정의)
  - 퀘스트: 실제 사례 기반 가상 사건을 단계별로 해결. 홈은 단계 지도(현재 단계만 열리고 이후는 잠김). 동적인 분위기.
  - 일반 학습: 사건 요소 없이 개념만 빠르게. 카테고리 → 주제 → 개념 페이지, 수동 '완료' 표시 → 카드 색 변경. 정돈된 분위기.
- 역량 축은 정확히 5개: OS · 네트워크 · 인프라 · DB · AI. 분산 시스템·관측성은 축이 아니라 주제.
- 역량 점수: 사건 해결과 일반 학습 완료 모두 반영(2026-11-20). 산식은 임시(catalog.json `competency`).
- '도움받아 해결'과 '독립 해결'을 구분한다. 개념 열람은 도움이 아니다. 힌트 사용·최종 판단 재제출은 도움이다. 중간 체크포인트 오답은 영향 없음(2026-11-20).

## 사건 화면
- 형식은 추리형(템플릿 A): 증거 선택 + 짧은 판단 근거(2026-11-20).
- 화면 중심은 사건마다 다른 **보드**. 분야뿐 아니라 주제에 따라 바뀐다(OS라고 모두 터미널은 아님). AI는 마우스로 체험하는 보드(2026-11-20).
- 한 화면의 카드는 4개 이하, 메인에 집중(2026-11-20).
- 가상 시뮬레이션 터미널 허용(실제 서버·셸 아님). `help`는 전체 명령 목록을 보여 준다(2026-11-20).
- 보조 학습은 없앴다. 막히면 해당 개념 페이지 링크만 준다(2026-11-20).
- 플립카드는 일반 학습의 복습 덱으로, 퀘스트에서는 용어 팝오버(2026-11-20, "일단 그렇게").
- 게임 보상(경험치·아이템·재화·처벌)은 넣지 않는다.

## 채점·콘텐츠
- 채점은 실제 답안지(증거 줄 규칙)로 한다. 답안지는 블라인드 교차 검증 후 확정한다. 동료·AI 답으로 평가하지 않는다(2026-11-20). 절차: docs/playbooks/answer-key-cross-check.md
- 서술 근거는 채점하지 않고 자기 점검 체크리스트로만 쓴다(2026-11-20, 'A안').
- 사건 소재는 국내 기업 기술 블로그의 트러블슈팅 사례(AI 제외). 목적은 판단의 갈림길·확인할 증거·사전 개념을 기르는 것(2026-11-20). 회사·수치·시스템을 바꾼 가상 사건으로 만든다.
- 시즌 1 순서는 docs/research/CASES.md 의 10단계로 진행(2026-11-21 "일단 저 순서로").
- inc-003(터미널)을 inc-002보다 먼저 만들어 사용자가 과정을 검증한다. 컨펌 후 진행(2026-11-21).
- 해결 후 결과 화면에 참고한 공개 사례 링크를 보여 준다 — **시험 표시, 확정 아님**(2026-11-21).

## 운영·작업 방식
- 웹사이트로 제공. 배포 대상은 OCI-2(2026-11-20). 배포 방식: main push → OCI-2 site-pull.timer(2분)가 받아 nginx가 dist/ 서비스(2026-11-22 사용자 확인). 그래서 dist/ 를 커밋한다.
- 작업 분담: 인터뷰 → docs/intent/<주제>.md → 새 세션에서 Claude 구현·테스트 → NEON 읽기 전용 검수(2026-11-22, 전역 규칙).
